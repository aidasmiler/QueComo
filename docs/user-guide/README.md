# Guías de usuario

Estas guías se generan automáticamente desde la ayuda integrada de la app (Perfil → Ayuda y soporte), en español e inglés, para que ambas versiones digan siempre lo mismo. Para cambiarlas, edita `src/i18n/locales/*/help.json` y ejecuta `node scripts/generate-user-guide.mjs` (CI comprueba que están al día).

- [Primeros pasos](GETTING_STARTED.md)
- [Hogares e invitaciones](HOUSEHOLDS.md)
- [Recetas y raciones](RECIPES.md)
- [Instalar la app](INSTALLATION.md)
- [Configuración e idioma](SETTINGS.md)
- [Preguntas frecuentes](FAQ.md)

Las guías de recetas, menú y compra se añadirán cuando esas funciones estén disponibles.
