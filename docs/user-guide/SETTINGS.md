## Español

### Cambiar de idioma

Ve a Perfil → Configuración → Idioma y elige Español o English.

El idioma es personal: cada persona del hogar puede usar el suyo. Las recetas y notas no se traducen.

## English

### Changing language

Go to Profile → Settings → Language and choose Español or English.

Language is personal: each person in the household can use their own. Recipes and notes are not translated.
